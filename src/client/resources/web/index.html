Setup

Craft

Crafts or smelts the item, making any missing ingredients first. Needs the crafting table and/or furnace saved in Setup, and the raw materials (plus fuel for smelting) in storage. The bot waits at the furnace while it smelts, about 10s an item.

Gather

Any item a block drops: ores, logs, string from cobwebs, saplings and apples from leaves, seeds from grass. Mines with Baritone until that many are picked up, bringing everything back to storage whenever the inventory fills. Equips a suitable tool first - from its own inventory, storage, or by crafting one - and swaps in a new one if it breaks. Naming an ore gathers what it drops. Stops if Baritone starts breaking anything in the storage region.
